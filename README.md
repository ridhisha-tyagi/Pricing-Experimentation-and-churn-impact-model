# Pricing Experimentation & Churn Impact Model

This project analyzes pricing structures through behavioral splits,
micro-experiments, and a churn impact model.

It is designed to help teams:
- Evaluate pricing risk before rollout
- Design guardrail-aware experiments
- Understand churn pressure from pricing decisions

Built using:
- Python
- Pandas
- Scikit-learn
- Streamlit
- Prepstack
